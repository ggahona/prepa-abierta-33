## Requisitos

Solo necesitas un navegador moderno. Algunos recursos usan:

- **MathJax** para renderizar fórmulas matemáticas (se carga desde CDN).
- **JavaScript** para las partes interactivas.

No requiere instalación ni conexión permanente después de la primera carga.
