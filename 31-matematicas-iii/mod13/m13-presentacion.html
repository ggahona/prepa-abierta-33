Bienvenida al Módulo 13

En este módulo estudiamos las funciones polinomiales, que generalizan las funciones lineales y cuadráticas que ya conoces. Una función polinomial tiene la forma:

$$f(x) = a_n x^n + a_{n-1} x^{n-1} + a_{n-2} x^{n-2} + \dots + a_0$$

donde $n$ es un entero no negativo y los coeficientes son números reales o complejos. Abordaremos:

  • Igualdad, suma y multiplicación de polinomios.
  • El algoritmo de la división: $f(x) = g(x) \cdot q(x) + r(x)$.
  • La división sintética para divisores de la forma $x - c$.

1. Definición y Grado

Una función polinomial se escribe como suma de monomios $a_k x^k$, llamados términos del polinomio:

$$f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_0$$

Grado de un polinomio

Si $a_n \neq 0$, decimos que la función polinomial es de grado $n$. El grado es el mayor exponente que aparece.

Completar términos faltantes

Es útil reescribir los polinomios con todas las potencias, usando coeficiente $0$ para las faltantes:

  • $f(x) = 4x^4 - 3x^2 + 1 = 4x^4 + 0x^3 - 3x^2 + 0x + 1$
  • $g(x) = 3x^3 - 2x^2 + x = 0x^4 + 3x^3 - 2x^2 + x + 0$

2. Igualdad y Suma de Polinomios

Igualdad

Dos polinomios $f(x)$ y $g(x)$ son iguales si y solo si los coeficientes de potencias iguales son iguales: $a_i = b_i$ para todo $i$.

Suma

La suma se define sumando los coeficientes correspondientes:

$$f(x) + g(x) = (a_n + b_n)x^n + (a_{n-1} + b_{n-1})x^{n-1} + \dots + (a_0 + b_0)$$

Elemento identidad e inverso aditivo

  • Identidad: $O = 0x^n + 0x^{n-1} + \dots + 0$, tal que $f(x) + O = f(x)$.
  • Inverso aditivo: $-f(x) = (-a_n)x^n + \dots + (-a_0)$, tal que $f(x) + (-f(x)) = O$.

3. Multiplicación de Polinomios

Se aplica la propiedad distributiva y las leyes de los exponentes: cada término del primer polinomio se multiplica por cada término del segundo y los resultados se suman.

Grado del producto

Si $f(x)$ tiene grado $n$ y $g(x)$ tiene grado $m$, entonces $f(x) \cdot g(x)$ tiene grado $\mathbf{n + m}$.

El término de mayor grado del producto es $(a_n b_m) x^{n+m}$.

💡 Propiedad del producto cero: si $f(x) \cdot g(x) = 0$, entonces $f(x) = 0$ ó $g(x) = 0$.
⚠️ Inverso multiplicativo: solo las funciones polinomiales de grado 0 (constantes no nulas) tienen inverso multiplicativo. Los demás polinomios no lo tienen en general.

4. Algoritmo de la División

El teorema de la división de polinomios dice:

📘 Teorema: si $f(x)$ y $g(x) \neq 0$, existen polinomios únicos $q(x)$ (cociente) y $r(x)$ (residuo) tales que: $$f(x) = g(x) \cdot q(x) + r(x)$$ donde $r(x) = 0$ o bien el grado de $r(x)$ es menor que el grado de $g(x)$.

Ejemplo: $x^4 + 3x^2 - 16$ entre $x^2 + 2x + 1$

Paso 1: Completar: $x^4 + 0x^3 + 3x^2 + 0x - 16$.

Paso 2: División larga término a término. Al final:

  • Cociente: $q(x) = x^2 - 2x + 6$
  • Residuo: $r(x) = -10x - 22$

Verificación:

$$x^4 + 3x^2 - 16 = (x^2 + 2x + 1)(x^2 - 2x + 6) + (-10x - 22)$$

5. División Sintética

Cuando el divisor es de la forma $x - c$, se puede usar el método abreviado llamado división sintética:

  1. Escribe solo los coeficientes del dividendo (usa $0$ para faltantes).
  2. Coloca $c$ a la izquierda.
  3. Baja el primer coeficiente.
  4. Multiplícalo por $c$ y escríbelo bajo el siguiente coeficiente; suma.
  5. Repite hasta terminar. El último número es el residuo.
  6. Los números anteriores son los coeficientes del cociente (grado uno menos que el dividendo).

Ejemplo: $2x^4 - 5x^3 + 3x^2 + 2x - 1$ entre $x - 2$

Aquí $c = 2$ y los coeficientes son $2, -5, 3, 2, -1$.

  • Cociente: $q(x) = 2x^3 - x^2 + x + 4$ (grado 3, uno menos que el dividendo)

6. Resumen del Módulo

Ideas clave

  • Una función polinomial es $f(x) = a_n x^n + \dots + a_0$ con $n$ entero no negativo.
  • El grado es el mayor exponente con coeficiente no nulo.
  • Dos polinomios son iguales si coinciden coeficiente a coeficiente.
  • La suma se hace sumando coeficientes correspondientes; existen elemento identidad $O$ e inverso aditivo $-f(x)$.
  • El producto tiene grado $n + m$ si los factores tienen grados $n$ y $m$.
  • Solo las constantes no nulas tienen inverso multiplicativo.
  • Algoritmo de la división: $f(x) = g(x) \cdot q(x) + r(x)$, con $\deg(r) < \deg(g)$.
  • La división sintética es un método abreviado para divisores $x - c$.
