Bienvenida al Módulo 2

En este módulo exploraremos los sistemas de ecuaciones lineales con dos variables, una herramienta fundamental en el álgebra para modelar y resolver problemas donde dos condiciones deben cumplirse simultáneamente.

Aprenderemos a identificar el conjunto solución, a interpretar geométricamente las relaciones entre las ecuaciones y a dominar tres métodos de resolución: gráfico, suma o resta, y la Regla de Cramer.

$$Ax + By + C = 0$$

Esta es la forma general de una ecuación lineal con dos variables. Un sistema de dos de estas ecuaciones busca el par ordenado $(x, y)$ que satisface ambas condiciones al mismo tiempo.

1. Conceptos Fundamentales y Tipos de Solución

El conjunto solución de un sistema de ecuaciones lineales es la intersección de los conjuntos solución de cada ecuación individual. Geométricamente, cada ecuación representa una línea recta en el plano cartesiano, lo que nos lleva a tres casos posibles:

  • Solución única: Las rectas se intersecan en un solo punto. El sistema es consistente y determinado.
  • Sin solución: Las rectas son paralelas y no coincidentes. El conjunto solución es vacío ($\emptyset$). El sistema es inconsistente.
  • Infinitas soluciones: Las rectas son coincidentes (son la misma recta). El sistema es consistente e indeterminado.

2. Método Gráfico

El método gráfico consiste en trazar ambas rectas en un mismo plano cartesiano. La solución del sistema es el par ordenado $(x, y)$ asociado al punto donde las gráficas se intersecan.

Para graficar una recta de forma eficiente, se calculan sus intersecciones con los ejes coordenados:

  • Intersección con el eje Y: Se hace $x = 0$ y se despeja $y$.
  • Intersección con el eje X: Se hace $y = 0$ y se despeja $x$.
$$3x + 2y = 6 \implies \text{Si } x=0, y=3 \quad \text{Si } y=0, x=2$$

Nota: Este método es excelente para la comprensión visual, pero su precisión depende de la escala del plano y puede ser aproximado si las soluciones no son números enteros.

3. Método de Suma o Resta

Este método algebraico elimina una de las incógnitas sumando o restando las ecuaciones. Para lograrlo, se multiplica una o ambas ecuaciones por una constante adecuada, de modo que los coeficientes de una variable queden iguales pero con signo contrario.

Ejemplo Resuelto

Resolver el sistema:

$$ \begin{cases} 3x + 2y = 5 \quad (1)\\ x + 3y = 4 \quad (2) \end{cases} $$

1. Multiplicamos la ecuación (2) por $-3$ para eliminar $x$: $-3x - 9y = -12$

2. Sumamos a la ecuación (1): $(3x + 2y) + (-3x - 9y) = 5 + (-12) \implies -7y = -7 \implies y = 1$

3. Sustituimos $y = 1$ en (2): $x + 3(1) = 4 \implies x = 1$.

La solución es el par ordenado $(1, 1)$.

4. Método de Cramer (Regla de Cramer)

La Regla de Cramer utiliza determinantes para resolver sistemas lineales. Para un sistema $2 \times 2$, se definen tres determinantes:

$$\Delta = \begin{vmatrix} A_1 & B_1 \\ A_2 & B_2 \end{vmatrix} = A_1B_2 - A_2B_1$$ $$\Delta_x = \begin{vmatrix} C_1 & B_1 \\ C_2 & B_2 \end{vmatrix} = C_1B_2 - C_2B_1$$ $$\Delta_y = \begin{vmatrix} A_1 & C_1 \\ A_2 & C_2 \end{vmatrix} = A_1C_2 - A_2C_1$$

Si $\Delta \neq 0$, el sistema tiene solución única dada por:

$$x = \frac{\Delta_x}{\Delta}, \quad y = \frac{\Delta_y}{\Delta}$$

Si $\Delta = 0$ y $\Delta_x \neq 0$ o $\Delta_y \neq 0$, el sistema es inconsistente (sin solución). Si todos son cero, hay infinitas soluciones.

Resumen y Cierre

¡Felicidades! Has completado el estudio de los sistemas de ecuaciones lineales con dos variables. A continuación, se sintetizan las ideas clave de este módulo:

  • Un sistema de ecuaciones lineales busca el punto de intersección común a dos rectas.
  • Los sistemas pueden tener una solución única, ninguna solución (paralelas) o infinitas soluciones (coincidentes).
  • El método gráfico ofrece una comprensión visual, mientras que los métodos de suma/resta y Cramer proporcionan precisión algebraica.
  • La Regla de Cramer es altamente eficiente para sistemas $2 \times 2$ y $3 \times 3$, utilizando el determinante principal $\Delta$ para clasificar y resolver el sistema.
