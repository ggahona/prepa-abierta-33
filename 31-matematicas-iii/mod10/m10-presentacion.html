Módulo 10 — Métodos de Solución para una Ecuación Cuadrática

Matemáticas III | Prepa Abierta 33

Bienvenida al Módulo 10

En este módulo estudiaremos los tres métodos principales para resolver una ecuación cuadrática de la forma:

$$ax^2 + bx + c = 0, \quad a \neq 0$$

El objetivo es determinar las raíces o ceros de la ecuación, es decir, los valores de $x$ que hacen cierta la igualdad. Los tres métodos son:

  • Gráfico: interpretar las intersecciones con el eje $X$.
  • Factorización: descomponer el trinomio en factores lineales.
  • Fórmula general: la herramienta más poderosa y universal.

1. Método Gráfico

Consiste en determinar la abscisa de los puntos donde la gráfica de $y = ax^2 + bx + c$ interseca o es tangente al eje $X$.

Ejemplos

  • La gráfica de $y = 2x^2 - 8x + 6$ interseca al eje $X$ en $x = 1$ ó $x = 3$.
  • La gráfica de $y = -2x^2 + 2x + 12$ interseca al eje $X$ en $x = -2$ ó $x = 3$.
Limitación del método gráfico: en la práctica se usa poco, ya que si las raíces no son números enteros, los puntos de intersección sólo se determinan de forma aproximada.

2. Método de Factorización

Este método se usa cuando el trinomio $ax^2 + bx + c$ se puede factorizar fácilmente. Se apoya en el Teorema del producto cero:

$$a \cdot b = 0 \iff a = 0 \quad \text{ó} \quad b = 0$$

Es decir, si un producto de factores es cero, entonces al menos uno de los factores debe ser cero.

Ejemplo 1: trinomio simple

Resolver $x^2 - 5x + 6 = 0$:

$$ \begin{aligned} x^2 - 5x + 6 &= (x - 3)(x - 2) = 0 \\ x - 3 = 0 &\quad \text{ó} \quad x - 2 = 0 \\ x = 3 &\quad \text{ó} \quad x = 2 \end{aligned} $$

Conjunto solución: $\{3, 2\}$

3. Factorización por Agrupación (Producto-Suma)

Cuando $a \neq 1$, se aplica el método del aspa o producto-suma. Veamos el proceso completo con el ejemplo $2x^2 + x - 6 = 0$:

  1. Multiplicar $a \cdot c$: $(2)(-6) = -12$.
  2. Buscar dos números cuyo producto sea $-12$ y cuya suma sea $b = 1$. Estos son $+4$ y $-3$.
  3. Descomponer el término lineal: $2x^2 + 4x - 3x - 6 = 0$.
  4. Agrupar: $(2x^2 + 4x) - (3x + 6) = 0$.
  5. Factorizar por agrupación: $2x(x + 2) - 3(x + 2) = 0$.
  6. Sacar factor común $(x + 2)$: $(2x - 3)(x + 2) = 0$.
  7. Igualar a cero cada factor: $2x - 3 = 0$ ó $x + 2 = 0$.
  8. Resolver: $x = \dfrac{3}{2}$ ó $x = -2$.

Conjunto solución: $\left\{\dfrac{3}{2}, -2\right\}$

4. Factorización sobre los Números Complejos

Algunas ecuaciones cuadráticas no se pueden factorizar sobre $\mathbb{R}$, pero sí sobre $\mathbb{C}$, usando $i^2 = -1$.

Ejemplo: $x^2 + 4 = 0$

Recordando que $i^2 = -1$, factorizamos como diferencia de cuadrados usando $i$:

$$x^2 + 4 = (x - 2i)(x + 2i) = 0$$
$$x = 2i \quad \text{ó} \quad x = -2i$$

Conjunto solución: $\{2i, -2i\}$

💡 Regla general: $x^2 + K = 0$ se factoriza como $(x - i\sqrt{K})(x + i\sqrt{K}) = 0$ cuando $K > 0$.

5. Deducción de la Fórmula General

La fórmula general se obtiene al aplicar el método de completar el cuadrado perfecto a la ecuación $ax^2 + bx + c = 0$:

  1. Dividir entre $a$: $x^2 + \dfrac{b}{a}x + \dfrac{c}{a} = 0$.
  2. Pasar el término independiente: $x^2 + \dfrac{b}{a}x = -\dfrac{c}{a}$.
  3. Sumar $\left(\dfrac{b}{2a}\right)^2$: $x^2 + \dfrac{b}{a}x + \dfrac{b^2}{4a^2} = \dfrac{b^2 - 4ac}{4a^2}$.
  4. Escribir como binomio: $\left(x + \dfrac{b}{2a}\right)^2 = \dfrac{b^2 - 4ac}{4a^2}$.
  5. Sacar raíz: $x + \dfrac{b}{2a} = \pm\dfrac{\sqrt{b^2 - 4ac}}{2a}$.
  6. Despejar $x$:
$$\boxed{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}}$$

Las dos raíces son:

$$x_1 = \frac{-b + \sqrt{b^2 - 4ac}}{2a} \quad \text{y} \quad x_2 = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$$

6. Ejemplos de la Fórmula General

La fórmula general es el método más poderoso y universal. Según el valor del discriminante $\Delta = b^2 - 4ac$, podemos tener:

  • $\Delta > 0$: dos raíces reales distintas.
  • $\Delta = 0$: una raíz doble (real).
  • $\Delta < 0$: dos raíces complejas conjugadas.

Ejemplo 1: raíces reales distintas

$x^2 + 3x - 10 = 0$ con $a = 1$, $b = 3$, $c = -10$:

$$x = \frac{-3 \pm \sqrt{9 + 40}}{2} = \frac{-3 \pm 7}{2} \implies x_1 = 2, \ x_2 = -5$$

Ejemplo 2: raíz doble

$x^2 - 4x + 4 = 0$ con $a = 1$, $b = -4$, $c = 4$:

$$x = \frac{4 \pm \sqrt{16 - 16}}{2} = \frac{4}{2} \implies x = 2 \text{ (doble)}$$

Ejemplo 3: raíces complejas

$5x^2 - 4x + 1 = 0$ con $a = 5$, $b = -4$, $c = 1$:

$$x = \frac{4 \pm \sqrt{16 - 20}}{10} = \frac{4 \pm 2i}{10} = \frac{2 \pm i}{5}$$

7. Resumen del Módulo

Comparación de los tres métodos

  • Gráfico: útil para visualizar las raíces, pero poco preciso si no son enteras.
  • Factorización: rápido y elegante cuando los factores son sencillos de encontrar.
  • Fórmula general: método universal que funciona siempre, incluso con raíces irracionales o complejas.

Ideas clave

  • Resolver una ecuación cuadrática significa encontrar sus raíces o ceros.
  • La factorización se basa en el Teorema del producto cero: $a \cdot b = 0 \iff a = 0$ ó $b = 0$.
  • Para factorizar cuando $a \neq 1$ se usa el método del producto-suma (o aspa).
  • Las ecuaciones del tipo $x^2 + K = 0$ se factorizan sobre $\mathbb{C}$ como $(x - i\sqrt{K})(x + i\sqrt{K}) = 0$.
  • La fórmula general es $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
  • El discriminante $\Delta = b^2 - 4ac$ determina la naturaleza de las raíces.
