Bienvenida al Módulo 5

En este módulo iniciamos el estudio del Conjunto de los Números Complejos, denotado por $\mathbb{C}$. Veremos que este conjunto contiene a los números reales y permite resolver ecuaciones que no tienen solución en $\mathbb{R}$, como $y = x^2 + 1$.

$$\mathbb{C} = \{z \mid z = (a, b); a, b \in \mathbb{R}\}$$

Nos enfocaremos en la definición de número complejo, la igualdad entre ellos, la operación de suma y sus propiedades conmutativa y asociativa, incluyendo el elemento identidad y el inverso aditivo.

1. El Conjunto de los Números Complejos

Ecuaciones como $y = x^2 + 1$ tienen gráficas que no intersecan al eje $X$. Esto significa que para ningún $x \in \mathbb{R}$ resulta $y = 0$, pues $x^2 + 1$ siempre es distinto de cero.

Cuando esto sucede, decimos que la ecuación no tiene solución en el conjunto de los números reales. Las soluciones están contenidas en un conjunto más amplio llamado El Conjunto de los Números Complejos, denotado por $\mathbb{C}$.

Definición formal

$$\mathbb{C} = \{z \mid z = (a, b); a, b \in \mathbb{R}\}$$

Un número complejo es un par ordenado con componentes reales. Cada número complejo se representa geométricamente como un punto del plano, y recíprocamente cada punto del plano representa un número complejo.

2. Igualdad de Números Complejos

Dos números complejos son iguales si y sólo si tienen el mismo primer componente y también son iguales sus segundos componentes.

$$z_1 = z_2 \text{ si y sólo si } a_1 = a_2 \text{ y } b_1 = b_2$$

Ejemplo

Si $(x, y) = (3, 2)$, entonces $x = 3$ y $y = 2$.

3. Suma de Números Complejos

La suma de dos números complejos se define componente a componente:

$$z_1 + z_2 = (a_1 + a_2, \ b_1 + b_2)$$

Como $a_1, a_2, b_1, b_2$ son números reales y $\mathbb{R}$ es cerrado respecto a la suma, la suma de dos números complejos es a su vez un número complejo. Decimos que $\mathbb{C}$ es cerrado respecto a la suma.

Ejemplo

$$(1, 2) + (3, -4) = (1 + 3, \ 2 + (-4)) = (4, -2)$$

4. Propiedades Conmutativa y Asociativa

Propiedad conmutativa

Para toda $z_1, z_2 \in \mathbb{C}$:

$$z_1 + z_2 = z_2 + z_1$$

Propiedad asociativa

Para toda terna $z_1, z_2, z_3 \in \mathbb{C}$:

$$z_1 + (z_2 + z_3) = (z_1 + z_2) + z_3$$

5. Elemento Identidad e Inverso Aditivo

Elemento identidad para la suma

El elemento identidad $(x, y)$ debe satisfacer $(a, b) + (x, y) = (a, b)$ para todo $(a, b) \in \mathbb{C}$. Esto ocurre si $x = y = 0$, por lo que el elemento identidad es $(0, 0)$.

$$(2, 3) + (0, 0) = (2, 3)$$

Inverso aditivo

El inverso aditivo de $(a, b)$ es el par ordenado $(-a, -b)$, pues:

$$(a, b) + (-a, -b) = (0, 0)$$

6. Demostración de la Propiedad Asociativa

Sean $z_1 = (a_1, b_1)$, $z_2 = (a_2, b_2)$, $z_3 = (a_3, b_3)$ tres números complejos. Demostramos que $z_1 + (z_2 + z_3) = (z_1 + z_2) + z_3$:

$$ \begin{align*} z_1 + (z_2 + z_3) &= (a_1, b_1) + [(a_2, b_2) + (a_3, b_3)] \\ &= (a_1, b_1) + (a_2 + a_3, \ b_2 + b_3) \\ &= (a_1 + (a_2 + a_3), \ b_1 + (b_2 + b_3)) \\ &= ((a_1 + a_2) + a_3, \ (b_1 + b_2) + b_3) \\ &= [(a_1, b_1) + (a_2, b_2)] + (a_3, b_3) \\ &= (z_1 + z_2) + z_3 \end{align*} $$

La propiedad se apoya en el postulado asociativo de la suma en $\mathbb{R}$, ya que las componentes son números reales.

7. Resumen del Módulo

Ideas clave

  • Un número complejo es un par ordenado $(a, b)$ con componentes reales.
  • El conjunto $\mathbb{C}$ contiene a $\mathbb{R}$ como subconjunto propio.
  • Dos números complejos son iguales si y sólo si sus componentes respectivas son iguales.
  • La suma se define componente a componente: $(a_1, b_1) + (a_2, b_2) = (a_1 + a_2, \ b_1 + b_2)$.
  • La suma es cerrada, conmutativa y asociativa en $\mathbb{C}$.
  • El elemento identidad para la suma es $(0, 0)$.
  • El inverso aditivo de $(a, b)$ es $(-a, -b)$.
